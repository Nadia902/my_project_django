## 📖 О проекте

Веб-сайт о здоровом питании с возможностью:

- 🍱 **заказа доставки еды**;
- 🧬 **подбора индивидуального рациона** на основании введённых пользователем данных (вес, рост, возраст, цель, активность и т.д.).

Проект разработан как **дипломная работа** с использованием фреймворка **Django** (Python).

---

## 🧰 Стек технологий

| Слой | Технологии |
| ---- | ---------- |
| **Backend**  | Python, Django |
| **Frontend** | HTML5, CSS3, JavaScript |
| **БД**       | SQLite (по умолчанию в Django) |

---

## ✨ Возможности

- 🧾 Регистрация и авторизация пользователей
- 📝 Ввод персональных данных для расчёта рациона
- 🥦 Подбор индивидуального меню (КБЖУ)
- 🛒 Корзина и оформление заказа
- 🚚 Оформление доставки еды
- 📚 Каталог блюд и рецептов
- 📱 Адаптивная вёрстка
